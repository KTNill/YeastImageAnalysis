# YeastImageAnalysis

酵母画像を対象に、透過光画像（BF）と蛍光画像（FL）を組み合わせて、細胞数および油脂蓄積・生産量を定量化するためのGUIアプリケーションです。

Cellpose によるセグメンテーションを用いて、細胞領域と油脂領域を検出し、解析結果をCSVと画像として出力します。

## 主な機能

- 画像フォルダを選択して一括解析
- 透過光画像（BF）から細胞を検出
- 蛍光画像（FL）から油脂領域を検出
- 細胞内油脂量・総油脂量・細胞内外分布を算出
- 解析結果をCSVとして保存
- マスク重畳画像・統合画像を保存
- 設定CSVによる解析パラメータ変更
- GUI上で解析ログと進捗を表示
- ファイル名や重要ログをハイライト表示
- モデル設定が変わらない場合は解析モデルを再利用

## 起動方法

### Windows

プロジェクト直下の以下を実行します。

```text
起動ファイル.bat
```

この起動ファイルは、プロジェクト内の `python_env` を使用して `main.py` を実行します。

```bat
.\python_env\python.exe .\main.py
```

### Pythonから直接起動する場合

仮想環境を有効化したうえで、以下を実行します。

```bash
python main.py
```

## 設定ファイル

解析設定は以下のCSVで管理します。

```text
config/settings.csv
```

初回起動時、設定ファイルが存在しない場合はデフォルト設定で自動作成されます。

主な設定項目は以下です。

| 項目名 | 内容 |
|---|---|
| 細胞モデルパス | 細胞検出用のカスタムモデルパス |
| 細胞径 | 細胞の想定直径 |
| 細胞フロー閾値 | Cellposeの細胞フロー閾値 |
| 細胞確率閾値 | Cellposeの細胞確率閾値 |
| 細胞最小サイズ | 検出する細胞の最小サイズ |
| 油脂モデルパス | 油脂検出用のカスタムモデルパス |
| 油脂径 | 油脂領域の想定直径 |
| 油脂フロー閾値 | Cellposeの油脂フロー閾値 |
| 油脂確率閾値 | Cellposeの油脂確率閾値 |
| 油脂最小サイズ | 検出する油脂領域の最小サイズ |
| 透過光画像識別子 | BF画像を識別する文字列 |
| 蛍光画像識別子 | FL画像を識別する文字列 |
| GPU使用 | GPUを使用する場合は `1`、使用しない場合は `0` |

## 画像ファイルの命名規則

BF画像とFL画像は、設定CSVの識別子に基づいてペアリングされます。

デフォルト設定では以下です。

```text
透過光画像識別子: _BF
蛍光画像識別子: _FL
```

例：

```text
sample01_BF.tif
sample01_FL.tif
```

この場合、`sample01_BF.tif` と `sample01_FL.tif` が1セットとして解析されます。

BF識別子はファイル名末尾にあることを前提とします。

有効な例：

```text
sample01_BF.tif
```

スキップされる例：

```text
sample01_BF_backup.tif
```

画像拡張子は以下に対応しています。

```text
.png
.jpg
.jpeg
.tif
.tiff
```

## 解析結果

解析を実行すると、選択した画像フォルダ内に以下の形式で結果フォルダが作成されます。

```text
result_YYYYMMDD_HHMMSS/
```

出力内容の例：

```text
result_20260521_153000/
├── used_settings.csv
├── analysis_summary.csv
├── 01_cell_sample01_BF.tif
├── 02_lipid_sample01_BF.tif
└── 03_combined_sample01_BF.tif
```

### 出力CSV

`analysis_summary.csv` には、画像ごとの解析値と全体統計が出力されます。

主な出力項目は以下です。

| 項目 | 内容 |
|---|---|
| ファイル名 | 解析対象のBF画像名 |
| 細胞数 | 検出された細胞数 |
| 細胞面積(px) | 細胞マスクの総ピクセル数 |
| 油脂占有率 | 細胞内油脂面積 / 細胞総面積 |
| 総生産率 | 全油脂面積 / 細胞総面積 |
| 細胞内油脂割合(%) | 細胞内油脂面積 / 全油脂面積 × 100 |

## 指標の定義

本アプリでは、油脂関連指標を以下のように定義しています。

```text
油脂占有率 = 細胞内の油脂面積 / 細胞の総面積
総生産率 = 全油脂面積 / 細胞の総面積
細胞内油脂割合 = 細胞内の油脂面積 / 全油脂面積
細胞外油脂割合 = 細胞外の油脂面積 / 全油脂面積
```

## GUIの使い方

1. アプリを起動する
2. `画像フォルダを選択` を押して解析対象フォルダを選択する
3. 必要に応じて解析対象を選択する
   - 細胞解析（BF）
   - 油脂解析（FL）
4. `解析開始` を押す
5. 進捗バーとログで解析状況を確認する
6. 解析完了後、ログに表示される結果保存先を確認する

## 解析モデルの再利用

解析開始時に設定CSVを再読み込みします。

ただし、以下のモデル関連設定が変わっていない場合は、既存の解析モデルを再利用します。

```text
細胞モデルパス
油脂モデルパス
GPU使用
```

これにより、細胞径・閾値・最小サイズ・描画色などを変更して再解析する場合、モデル再読み込みを避けて解析開始時間を短縮できます。

モデル関連設定が変更された場合は、解析モデルを再初期化します。

## GPU利用について

`config/settings.csv` の `GPU使用` によりGPU利用を切り替えます。

```text
1: GPUを使用
0: GPUを使用しない
```

CUDAが利用可能な場合はCUDAを優先します。  
macOS環境ではMPSが利用可能な場合にMPSを使用します。  
利用可能なGPUがない場合はCPUで解析します。

## 注意事項

- BF画像とFL画像のサイズが一致している必要があります。
- 対応するFL画像が見つからない場合、そのセットはスキップされます。
- 画像読み込みに失敗した場合、その画像はスキップされます。
- 解析中に個別画像でエラーが発生した場合、その画像はスキップされ、次の画像の解析を継続します。
- `python_env` は起動ファイル用の実行環境として扱い、IDEの開発用インタープリタとは分けることを推奨します。

## 開発時の注意

IDEでは開発用の仮想環境を使用し、BAT起動用の `python_env` を誤って書き換えないようにしてください。

推奨運用：

```text
python_env : 起動ファイル用の固定実行環境
venv       : IDE開発・テスト用環境
```

IDEアップデート後などに、プロジェクトインタープリタが意図せず `python_env` に変わっていないか確認してください。

## トラブルシューティング

### 「画像が見つかりません」と表示される

以下を確認してください。

- 選択したフォルダに画像ファイルが存在するか
- 拡張子が対応形式か
- BF識別子が設定CSVと一致しているか
- BF識別子がファイル名末尾にあるか

例：

```text
設定CSV: _BF
有効なファイル名: sample01_BF.tif
```

### `operator torchvision::nms does not exist` が表示される

`torch` と `torchvision` の組み合わせ、またはインストール状態が壊れている可能性があります。

BATと同じPythonで以下を確認してください。

```bat
.\python_env\python.exe -m pip show torch torchvision
```

```bat
.\python_env\python.exe -c "import torch; import torchvision; print
